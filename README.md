# Biblioteca API

API REST desenvolvida com Spring Boot 3 e Java 21.

## Tecnologias

- Java 21
- Spring Boot
- Spring Data JPA
- PostgreSQL
- Swagger/OpenAPI

## Funcionalidades

- CRUD de livros
- CRUD de autores
- CRUD de categorias
- Validações
- Tratamento global de exceções
